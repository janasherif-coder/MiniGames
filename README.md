### 🕹️ Games Included

### ❌ XO (Tic-Tac-Toe)

<p>
  A classic two-player game played on a 3×3 grid. Players take turns placing X and O, aiming to get three symbols in a row, column, or diagonal to win.
</p>

- 👥 Two-player gameplay.
- 🎯 Win detection.
- 🤝 Draw detection.
- 🎮 Interactive gameplay.

### ✊ Rock Paper Scissors

<p>
  A classic game where the player competes against the computer by choosing Rock, Paper, or Scissors. The computer generates a random choice, and the winner is determined according to the game rules.
</p>

- 👤 Player vs. Computer.
- 🎲 Random computer choices.
- 🏆 Winner detection.
- 🔄 Replay option.
